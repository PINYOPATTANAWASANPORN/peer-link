# Peer brand assets

The three `peer-logo-*.svg` files are unchanged official Peer wordmarks, supplied for this Peer project. Use the [Peer brand guidelines](https://docs.peer.xyz/brand-kit). Do not redraw, recolor, distort, rotate or combine the wordmark paths with other marks. The separate Link label identifies this project.

The page uses Inter as a fallback; no proprietary font files are redistributed.
