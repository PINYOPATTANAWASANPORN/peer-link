# Ualá Argentina Adapter

Pure deterministic banking adapter for Ualá Argentina (Argentina / ARS) CVU/Alias transfer records.

## Specifications
- **Country:** Argentina (`AR`)
- **Currency:** `ARS` (minor units: 2, 100 centavos = 1 ARS)
- **Supported Payment Types:** CVU a CVU, Transferencia por Alias / CBU
- **Identifier:** `coelsaId` / `idOperacion` (e.g. `COELSA-984729104829`)
- **Statuses Supported:** `COMPLETADA`, `ACREDITADA`, `EXITOSA`, `SETTLED`
