# bKash (Bangladesh) Adapter

Pure deterministic banking adapter for bKash (Bangladesh / BDT) Send Money transactions.

## Specifications
- **Country:** Bangladesh (`BD`)
- **Currency:** `BDT` (minor units: 2, 100 poisha = 1 BDT)
- **Supported Payment Types:** bKash-to-bKash Send Money, P2P, Merchant transfers
- **Identifier:** `trxId` (e.g. `BL63G9X2M1`)
- **Statuses Supported:** `COMPLETED`, `SUCCESS`, `SUCCESSFUL`, `SETTLED`
